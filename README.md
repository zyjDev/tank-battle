# 坦克大战

经典的坦克大战游戏，使用纯 HTML/CSS/JavaScript 实现，无需任何依赖。

## 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏。

```
双击 index.html
# 或在终端运行
start index.html
```

## 操作

| 按键 | 功能 |
|------|------|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 空格 | 射击 |

## 游戏规则

- 消灭所有敌方坦克即可过关
- 保护基地（★）不被摧毁
- 共 3 关，难度逐渐提升
- 砖墙可以被子弹摧毁，钢墙不可以
- 水域无法通过，树林可以隐藏坦克

## 敌方坦克

| 类型 | 颜色 | 特点 |
|------|------|------|
| 普通 | 红色 | 均衡型 |
| 快速 | 橙色 | 移动快，射速快 |
| 重装 | 紫色 | 3 点血量 |
| 精英 | 绿色 | 最快移动，最高射速 |

## 技术栈

- HTML5 Canvas 渲染
- 原生 JavaScript，无框架依赖
- 单文件实现，便于部署
